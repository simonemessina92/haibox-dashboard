HAIBOX Local Dashboard 5.0.0 GOLDEN

New installations start with 12 empty tiles. Long press a tile to edit it, or use Settings > Import Config to load a HAIBOX JSON configuration.

Update: export your configuration as a backup, replace the files in the existing extension folder, then click Reload at chrome://extensions. Existing saved tiles are preserved. Do not remove the extension to update it.

Chrome startup: select Open the New Tab page.

Configuration imports replace all tiles and the logo after confirmation. Existing V4 exports remain supported.
